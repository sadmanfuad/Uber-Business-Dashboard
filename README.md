# Uber-Business-Dashboard
The main objective of this dashboard is to evaluate Uber’s performance over time and understand the customer experience, including ride choices, ratings, and feedback. It also aims to identify the biggest problems customers face when using the app and service, such as cancelled and incomplete rides.


📊 What I found:

🔹 Auto leads the platform with ~23K completed bookings and ~13M in revenue, the highest of any ride type

🔹 Bikes come second with ~21K completed bookings, so affordable short rides drive demand

🔹 Lost bookings are a real problem. Across all ride types, roughly 56K bookings were lost against ~94K completed. That’s a big opportunity for better driver availability

🔹 Uber XL is a niche segment with only ~3K completed bookings, but a steady monthly pattern

🔹 Average trip distance stays consistent (~24.4 to 24.8) across every ride type, while average driver rating holds steady around 4.23

💡 Why it matters: Dashboards like this help answer questions about pricing, driver supply, and service quality, which is where data turns into decisions.
